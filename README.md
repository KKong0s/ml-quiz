# ML ขั้นสูง ทบทวนข้อสอบ

เว็บแอปสำหรับฝึกทำข้อสอบวิชา **0452330267 การเรียนรู้ของเครื่องขั้นสูง** มีทั้งหมด 200 ข้อ (ปรนัย 181 ข้อ จับคู่ 19 ข้อ) ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ ติดตั้งเป็นแอปได้ และเปิดใช้ได้แม้ไม่มีอินเทอร์เน็ต

เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มีขั้นตอน build

```
index.html             หน้าเว็บ
style.css              หน้าตา (รองรับโหมดสว่าง/มืด)
app.js                 การทำงานทั้งหมด
questions.json         ข้อสอบ
manifest.webmanifest   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                  service worker สำหรับใช้งานออฟไลน์
icons/                 ไอคอนแอป
```

## 1. ทดสอบในเครื่อง

> **ห้ามเปิด `index.html` ด้วยการดับเบิลคลิก** (ที่อยู่จะขึ้นต้นด้วย `file://`) เพราะ `fetch()` และ service worker จะไม่ทำงาน ต้องเปิดผ่านเว็บเซิร์ฟเวอร์เท่านั้น

**วิธีที่ 1: ส่วนขยาย Live Server ใน VS Code**
1. ติดตั้งส่วนขยาย **Live Server** (ของ Ritwick Dey)
2. คลิกขวาที่ `index.html` แล้วเลือก **Open with Live Server**
3. เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:5500/`

**วิธีที่ 2: ใช้คำสั่ง**
```bash
npx serve .
```
แล้วเปิดลิงก์ที่ขึ้นในเทอร์มินัล (ปกติคือ `http://localhost:3000`)

**ทดสอบโหมดออฟไลน์:** เปิดเว็บหนึ่งครั้ง กด F12 ไปที่แท็บ **Network** เปลี่ยน *No throttling* เป็น **Offline** แล้วรีโหลด หน้าเว็บต้องยังใช้งานได้

## 2. นำขึ้น GitHub Pages

1. เข้า <https://github.com/new> สร้าง repository ใหม่ เช่น `ml-quiz` (เลือก **Public**)
2. push ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป:
   ```bash
   git init
   git add .
   git commit -m "ML quiz"
   git branch -M main
   git remote add origin https://github.com/<username>/ml-quiz.git
   git push -u origin main
   ```
   (หรือใช้ปุ่ม **Source Control** ใน VS Code / ลากไฟล์ขึ้นผ่านหน้าเว็บ GitHub ด้วย *Add file → Upload files* ก็ได้)
3. ใน repository ไปที่ **Settings → Pages**
4. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**
5. ที่ **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอ 1–2 นาที แล้วรีเฟรชหน้า Settings → Pages จะเห็นลิงก์ เช่น `https://<username>.github.io/ml-quiz/`

ทุกไฟล์ใช้ path แบบ relative (`./app.js`) จึงทำงานใต้ sub-path ของ GitHub Pages ได้เลยโดยไม่ต้องแก้อะไร

## 3. ติดตั้งบนมือถือ

เปิดลิงก์ GitHub Pages บนมือถือหนึ่งครั้งตอนมีเน็ต แล้วติดตั้ง:

- **Android (Chrome):** กดเมนู **⋮** มุมขวาบน → **ติดตั้งแอป** (หรือ *เพิ่มลงในหน้าจอหลัก*)
- **iPhone / iPad (Safari):** กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**

หลังติดตั้งแล้วจะมีไอคอน "ML Quiz" บนหน้าจอ เปิดใช้ได้แม้ไม่มีอินเทอร์เน็ต

## 4. เพิ่มหรือแก้ข้อสอบ

แก้ไฟล์ `questions.json` ได้โดยตรง

**ข้อปรนัย (`mc`)**
```json
{
  "id": "q9999",
  "source": "IMG_9999.JPG",
  "module": "m3",
  "type": "mc",
  "question": "คำถาม",
  "options": ["ตัวเลือก a", "ตัวเลือก b", "ตัวเลือก c", "ตัวเลือก d", "ตัวเลือก e"],
  "answer": 1,
  "explanation": "คำอธิบายเฉลย"
}
```
- `answer` คือลำดับของตัวเลือกที่ถูก **เริ่มนับจาก 0** (a = 0, b = 1, …, e = 4)

**ข้อจับคู่ (`match`)**
```json
{
  "id": "m9999",
  "source": "IMG_9999.JPG",
  "module": "m3",
  "type": "match",
  "question": "จับคู่คำศัพท์กับคำอธิบาย",
  "pairs": [
    { "term": "mAP", "answer": "คำอธิบายที่ถูก" },
    { "term": "IoU", "answer": "คำอธิบายที่ถูก" }
  ]
}
```

ข้อควรระวัง:
- `id` ต้องไม่ซ้ำกับข้ออื่น (คำตอบที่บันทึกไว้ผูกกับ `id`)
- `module` ต้องตรงกับ `id` ในรายการ `modules` ด้านบนของไฟล์
- ตรวจว่า JSON ถูกต้อง เช่น ไม่มีจุลภาค `,` เกินหลังรายการสุดท้าย

**สำคัญ: ทุกครั้งที่แก้ไฟล์ใดก็ตาม ต้องเปลี่ยนเลขเวอร์ชัน cache ใน `sw.js`** มิฉะนั้นเครื่องที่เคยเปิดแล้วจะยังเห็นไฟล์เก่า

```js
const CACHE_VERSION = 'v1';   // เปลี่ยนเป็น 'v2', 'v3', ... ทุกครั้งที่แก้ไฟล์
```

จากนั้น push ขึ้น GitHub ผู้ใช้จะได้ไฟล์ใหม่เมื่อเปิดเว็บครั้งถัดไป (บางครั้งต้องปิดแล้วเปิดแอปใหม่ 1–2 ครั้ง)

## การใช้งาน

- เลือกชุดข้อสอบจากแถบด้านบน (ทั้งหมด หรือแต่ละ Module)
- **ข้อปรนัย:** แตะตัวเลือก จะล็อกคำตอบและแสดงเฉลยทันที
- **ข้อจับคู่:** เลือกคำอธิบายให้ครบทุกช่อง แล้วกด **ตรวจคำตอบ**
- ตัวกรอง: สลับตัวเลือก, สลับลำดับข้อ, เฉพาะข้อที่ผิด, เฉพาะข้อที่ยังไม่ทำ
- **ล้างคำตอบชุดนี้** จะล้างเฉพาะชุดที่เลือกอยู่ (มีขั้นยืนยัน)
- คีย์ลัด: `1`–`5` เลือกคำตอบ, `←` `→` เปลี่ยนข้อ
- บนมือถือ: ปัดซ้าย/ขวาที่การ์ดข้อสอบเพื่อเปลี่ยนข้อ
- ความคืบหน้าบันทึกไว้ในเบราว์เซอร์ของเครื่องนั้น (ไม่ซิงก์ข้ามเครื่อง และจะหายถ้าล้างข้อมูลเว็บไซต์)
